# Tunnel Vision

A 3D endless tunnel runner for Android, built solo in Godot 4 with GDScript.

![Gameplay](screenshots/gameplay.gif)

## About
Tunnel Vision is a fast-paced endless runner where you [dodge obstacles / steer through a rotating tunnel / etc.] for as long as you can. I designed, built, and tested it solo in about two weeks, using AI tools throughout development.

## Features
- [Endless procedurally generated tunnel]
- [Increasing speed and difficulty]
- [High score tracking]
- Smooth performance on mobile

## Controls
- [Swipe left/right to steer]

## Built With
- Godot 4
- GDScript

## Status
Complete and playable. Google Play release coming soon.

## Running Locally
1. Install [Godot 4](https://godotengine.org/download)
2. Clone this repo
3. Open Godot, click **Import**, and select `project.godot`
4. Press **F5** to play
